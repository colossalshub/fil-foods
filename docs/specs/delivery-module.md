# Delivery module (User Story v6)

Index only. Acceptance criteria are in [`User_Story_v6_20_11_2026.xlsx`](./User_Story_v6_20_11_2026.xlsx), sheet Delivery Module. Map: [`meal-service-modules.md`](./meal-service-modules.md).

**Scope:** DEL-01–DEL-13 and DEL-15–DEL-17. There is no DEL-14. Delivery Staff have no menu.

**Precondition:** The Delivery Staff member has a staff account created by the Admin and is logged in. Paid orders marked Ready for Pickup and assigned for delivery exist.

**Postcondition:** Delivery progress is saved, the Admin and user can see the updated status, and the action is logged.
